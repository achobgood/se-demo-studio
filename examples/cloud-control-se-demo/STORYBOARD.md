## Notes on the cut

- **One cut between takes**, at 3:43.45 (t6 rec 609.5 s to t7 rec 15.0 s), on the same canvas, while
  the camera moves from the footer to the top bar. The t7 canvas card is empty for about a second
  and the context count reads "Context 3" instead of "Context 2". t7 was recorded in light theme to
  replace t6's tail, which went dark mid-take (`logs/state_changes.md`, 21:39).
- **Speed ramps with a chip:** analysis (about 12x), Default answer, Reasoning (about 6x), ThousandEyes
  load. **Without a chip:** the Actions list, canvas open, the path view load, the return to the
  canvas, and Generate summary.
- **Picture-sync gaps** (all flagged in `research/CLAIMS.md`): the switch row is not readable during
  row 8; the Analysis paragraph is not on screen during row 9; the report appears after the Generate
  summary line (row 21) with a half-faded first frame.
- **What the cut does not show** (absent from this build or run): Assign, Resolve, a workflow
  configuration or review screen, a Reasoning plan review, an "Investigation limitations" section.
